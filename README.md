# 酱油鱼 · 一个住在 QQ 群里的赛博鱼

「酱油鱼」是一个跑在**本机 Windows** 上的 QQ 机器人人格：底子是 [SnowLuma](https://github.com/snowluma/snowluma)
（把 QQ NT 转成 OneBot v11），脑袋是 [NoneBot2](https://nonebot.dev/) + 大模型，记忆放在白守（BaiShou）的
Markdown 日记里，眼睛是本地 OCR + 一个 2B 的视觉小模型。

它不追求「有用」：在群里说话像个普通群友，短、口语、有点脾气；被叫到才应、聊得热乎了会接话、
偶尔路过插一句嘴；被追问烦了会直接冷处理一百秒。真正被问正经事时又会正经答。

> 自用项目，跑在一台家用 PC 上，不面向公网、不做多租户。里面的 token、密码、QQ 号全部是占位符，
> 自己部署时请换成自己的。

## 它长什么样

```
QQ NT 客户端（桌面版，已登录）
      │  本机进程注入（SnowLuma 自带 hook）
      ▼
SnowLuma  ── WebUI 127.0.0.1:5099   OneBot HTTP 3000 / WS 3001
      │  反向 WebSocket（Universal 客户端）
      ▼
NoneBot2  127.0.0.1:18080/onebot/v11/ws
      ├── persona       人设 / 情绪 / 接话判定 / 模式（省话·话痨·静音·米游抽卡）
      ├── vision        图卡：表情哈希匹配 → Windows OCR → 本地视觉模型
      ├── memory        白守 Markdown 日记（/记 /回忆 /记忆）
      ├── stickers      513 张表情包（含 93 张 GIF）
      ├── GenshinUID    早柚核心连接插件：游戏查询转给核心（另起进程，原神/星铁/绝区零/崩坏3/鸣潮/终末地）
      ├── cache_cleanup 下载媒体 24h 自动清理
      └── parser        哔哩哔哩/微博/抖音/小红书…链接解析（视频直发原片）
      ▼
DeepSeek（OpenAI 兼容接口）—— 只在真要回话时才调用
```

## 功能

**说话**
- 人设是二次元傲娇美少女：底子是傲，爱顶嘴、嘴硬；只有偶尔抽中时才露一点真心（陌生人 0、普通群友 4%、有好感 10%、很亲近 20%）。
  可以毒舌、放狠话，但都是斗嘴玩笑，绝不辱骂、不人身攻击；模型万一说出带脏话的回复，那句不发。
- 像真人打字：收到消息先等几秒看对方还说不说（同一个人接着发就再等等，被 @ 就快一点），拆开发的几句、跟着的表情当一件事一起回，
  不是一条一回；回话按字数「打字」，长句拆成两三条发，有时只回一个表情；打字时对方又补了话就带上重想，过时的回复不补发。
  群里她回之前别人已经插了话的，会引用原消息回。
- 每条 ≤20 字、一次最多 3 条，口语、不带括号动作/emoji、不提 AI，不说「总之」「确实」这类书面腔；求助类问题自动放宽到 80 字并给实质结论。
- 上下文接得上：最近 40 条进上下文，话题还在就顺着聊；回话路数（吐槽、接梗、反问……）同一个会话保持一阵，不每句换一种。
- 被 @ 必回，不受额度限制（连着 @ 好几次会合成一批回一次）。喊名字（没 @）回不回看好感：讨厌 10%、陌生 25%、普通 40%、有好感 55%、很亲近 70%，
  好感低的就算回也是敷衍；同样不受额度限制。
- 没人找时话少，偶尔冒个泡：同一个人在接续窗口内接着说才可能接话，一段最多来回 2 次；其余只有 2% 概率插一句（同群至少隔 45 分钟），
  聊到她感兴趣的（游戏、动画、吃喝、格斗、卡牌、音乐，`PERSONA_INTERESTS`）概率乘 4；模型看了觉得没兴趣就不插，连着几次就退避。
  这些没被叫的回话（含只发表情）同群至少隔 3 分钟、每小时最多 6 条，用到一半就不插话、不配图了。
- 只发表情要对得上场景：群友这句有明显场景（有人抽卡歪了 → 幸灾乐祸、出金 → 羡慕、卧槽 → 震惊、无语……）时，
  一半概率只甩一张图上的字、分类或用途备注对得上的表情；找不到对得上的就照常说话，同群至少隔 15 分钟。没有场景时 5% 随手甩张无厘头的。
  被叫和正经求助时不这样。
- 情绪跟随上一句：被「调教、捏、rua」会炸毛，被夸会得意又嘴硬；同一句追问太多会被判定为「烦」→ 冷处理 100 秒。
- 每条回复有冷却；群聊另有每分钟总额度（默认 4 条）和每群每小时额度（默认 6 条），都是用到一半停插话和配图，用到 3/4 停接续，用满才停被叫。
  私聊、被叫触发的抽卡定型文和游戏查询指令不受限。

**模式（每个群可以单独设，`/模式` 仅开发者可用）**

| 模式 | 被叫 | 接续 | 主动插话 | 同群冷却 |
|---|---|---|---|---|
| 省话（默认） | @ 必回 / 喊名字 10%–70% | 8% | 2% | 10s |
| 话痨 | 100% | 100% | 4% | 3s |
| 静音 | 0 | 0 | **0** | — |
| 米游抽卡 | 1.8% | 0 | 2% | 60s |

被 @ 在省话、话痨档必回（静音档不回，抽卡档照旧 1.8% 触发定型文）；喊名字的概率按态度取值、随档位等比缩放；接续按态度微调（讨厌 ×0.6 … 很亲近 ×1.3，设成 100% 的不打折）。

静音和插话彻底分开：静音就是一句话不说；`/插话` 可以单独把插话关掉或调成任意百分比。

**小本本（好感度、熟悉度和简短日记）**
- 每个群友按 QQ 号一份，群里的 A 和私聊的 A 是同一条记录，换个地方也认得。
- 好感难涨易掉：只有夸、谢才涨，越高越难涨，不熟的人涨不高；骂人、追着烦她会掉；超过 3 天没来往每天往回掉，
  过了 50 每天还会自然回落，天天对她好也只能停在「很亲近」门槛附近。态度分 讨厌 / 陌生 / 普通 / 有好感 / 很亲近 五档。
- 日记很短：每人最多 6 条、每群最多 8 条关系 + 4 条风格，每条 ≤20 字。聊几轮或有人说起自己的事时，让模型摘一两条；
  群里每 60 条消息（至少隔半小时）摘一次群友关系和本群的说话风格、常玩的梗，回话时往这个群的风格靠。
- 私聊里听来的事只在私聊用，不会在群里说出来；好感和熟悉度两边共用。
- `/小本本`（仅开发者）：群里看本群日记，`/小本本 @某人` 看某人，`/小本本 删除 @某人` 删掉关于这个人的全部记录（比如本人要求时）。

**看图和表情**
- 表情库用**多帧**感知哈希索引（513 张 / 736 帧）。QQ 把动图表情压成静态预览时，也能靠任意一帧认出来，
  输出 `[表情:动图｜其他｜截图选老婆]` 这种图卡，几 token 就够。
- 库外的图：Windows 自带 OCR（中文）+ 本地 Qwen3-VL-2B（llama.cpp）描述，图卡塞进上下文，一条 5–40 token。
- 有人追问「刚才那张图啥意思」时，会把最近一张图重新做成图卡补进上下文。
- 群友发了库里没有的表情，她会看心情收藏（20%，讨厌的人发的不收），存进 `stickers/saved/`，以后配图会优先挑自己收藏的。
  这是机器人自己的本地表情库，OneBot 没有往 QQ「收藏表情」里加图的接口。
- 表情小本本（`stickers/notes.json`）：每张表情的用途备注和用过几次。收藏时按当时的场景记用途，之后在什么场景发过也补进去；
  按场景挑图时会看备注，用得多的更容易被挑中。`/表情 收藏` 看常用的几张，`/表情 备注 <id> <用途>`（仅开发者）手动写。

**其他**
- `/记`、`/回忆`、`/记忆`（仅开发者）：写/读白守库里 `Journals/` 下的 Markdown 日记；群里被叫和私聊会自动落盘，
  按群/私聊分开打标签，只在同一会话里被想起。
- 原神 / 星铁 / 绝区零 / 崩坏3 / 鸣潮 / 终末地：抽卡记录、深渊类战绩、角色面板等，由早柚核心提供（`gs帮助`、`sr帮助`、`zzz帮助`、`bbb帮助`、`ww帮助`、`zmd帮助`），
  私聊（可用群临时会话）发「扫码登录」绑定米游社账号；登录过的账号每天自动领签到奖励（六款游戏都签）；安装见 `docs/早柚核心接入.md`。
- 视频链接直接发原片（不渲染卡片），下载的媒体 24 小时自动清理。
- `/用量`：看当天 token 消耗与缓存命中率；`/圣经`：抽卡定型文（仅开发者）。

```

```

## 快速开始

前置：Windows 10/11、Git、QQ NT 桌面版。Python、uv、SnowLuma、早柚核心由脚本自动装。

```powershell
git clone https://github.com/Rindouchiaki/jiangyouyu-qq-bot.git
```

然后双击仓库根目录的 **`一键部署.cmd`**：问 API Key 和两个 QQ 号，装好全部依赖、生成配置（随机 token、只听 127.0.0.1），
接着在后台启动整套服务。之后日常用 `一键启动.cmd` / `一键停止.cmd`；GitHub 上合并了 PR（包括每天自动开的依赖更新 PR）以后双击 `一键更新.cmd`。
一键更新会把 `bot\persona.env` 的调参项换成新的默认值（账号、密钥、路径不动，先备份）；自己要长期保留的值写进 `bot\persona.local.env`。
完整步骤（第一次登录 SnowLuma、从旧的 `Z:\snowluma` 迁移、常见问题）见 **[`docs/部署指南.md`](docs/部署指南.md)**。

命令行等价写法（脚本会按端口跳过已在跑的服务）：

```powershell
.\scripts\setup.ps1 -Start          # 部署 + 启动（= 一键部署.cmd）
.\scripts\启动全部.ps1             # QQ → 本地视觉模型 → SnowLuma → 早柚核心 → NoneBot
.\scripts\启动全部.ps1 -Status     # 只看状态
.\scripts\启动全部.ps1 -Stop       # 全停（QQ 保留）
.\scripts\verify-stack.ps1         # 全链路自检
.\scripts\update.ps1               # 拉代码 + 依赖换到锁定版本 + 重启（= 一键更新.cmd）
```

## 成本

一次普通回复约 600 输入 token / 6 输出 token，DeepSeek 前缀缓存命中率约 30%（system 提示词固定在最前面）。
图卡方案让「看图」本身几乎不花 token —— 表情 5–12 token，OCR 文字 30–42 token，无字图才走本地小模型。
