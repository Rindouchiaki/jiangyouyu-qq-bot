# 群友机器人说话方式（群 532193003 数据）

对照对象：`3265642025`，群名片「Dizzy（开心开心）」，和我们同一套协议（SnowLuma → OneBot），但回复逻辑是它自己的。

数据来自 `289635657` 的群历史，用临时插件 `/_hist2` 分页拉取（`get_group_msg_history`，`message_id` 作锚点），落盘 `_research\group_532193003_long.jsonl`。分析脚本 `_research\analyze_group.py`、`analyze_dizzy.py`。

## 样本

- 14 天（2026-10-26 ~ 11-09）：36100 条群消息，其中 Dizzy 2394 条（6.6%）。
- 更长的 45 天样本在同一个 jsonl 里继续追加，统计口径不变。

## 它怎么发消息

| 项 | 数值 |
|---|---|
| 纯图片、不配字 | 1137 条（47%） |
| 纯文字 | 658 条（27%） |
| 文字 + 引用 + @ | 357 条（15%） |
| 转发（动态/卡片） | 173 条（7%） |
| 文字 + 图 | 33 条（1%） |
| 文字长度 | p50 24 字 / p75 35 / p90 49 / p99 402 |
| 长度分布 | ≤10 字 3%，11–20 字 38%，21–40 字 44%，41–80 字 11%，>80 字 4% |
| 完全不带标点 | 83% |
| 一次回合条数 | 中位 1，最多 10 |
| @ 的对象是上一句发言人 | 30%（其余 @ 别人或群友） |
| 被 @ 后多久回 | 中位 24 秒，≤10 秒 27% |

按小时的活跃度（≥峰值 60%）：0 点、11、12、14–17 点。

## 结论

1. **图是主要表达方式**，近一半消息只有一张图，且几乎不「图 + 字」混发。
2. **文字中等偏短**，常见 20–40 字，很少超过 80；断句靠空格，不用逗号句号。
3. **点名才引用**：引用 + @ 只出现在「回某个人的话」时，占 15%；其余是没人叫它时自己插话。
4. **一回合一兩句**，很少连发；被 @ 后平均 24 秒回，不是秒回。

## 我们照搬了什么

`PERSONA_PROFILE=groupmate`（`bot/groupmate.py`）：

| 参数 | 值 | 依据 |
|---|---|---|
| `max_chars` | 24 | 对方 p50 = 24 |
| `max_chars_question` | 48 | 对方 p75–p90 区间 |
| `sticker_only_called_prob` | 0.47 | 对方纯图占 47% |
| `sticker_only_prob` | 0.5 | 没人叫时也照场景甩图 |
| `polish()` | 去标点、空格断句 | 对方 83% 不带标点 |

没照搬的：转发动态卡片（我们走 B 站订阅，不刷屏）、超长文本（>80 字，占比 4%，我们的定位仍是短句）、@ 频率（对方 15% 带 @，我们只在被 @ 时 @ 回去，避免变成刷屏）。

回滚：删掉 `PERSONA_PROFILE` 或写 `classic`，重启即恢复原行为。
