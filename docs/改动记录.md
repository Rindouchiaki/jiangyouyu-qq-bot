# 改动记录

按时间倒序记每次功能改动：改了什么、为什么、动到哪些文件、怎么验证。
配置项都能在 `bot/persona.env` 里覆盖，这里标的是代码默认值。

## 2026-10-28

### 1. 初始好感度改成「礼貌档」（好感 10 / 熟悉 8 → 态度「普通」）

- 原因：新认识的人原来是 `好感 0 / 熟悉 0`，按 `attitude()` 直接落到「陌生」——回话敷衍、爱答不理，
  刚进群的人第一印象太差。
- 改动：
  - `bot/persona_rules.py`：新增 `INITIAL_AFF`（`BOND_INITIAL_AFF`，默认 10）、`INITIAL_FAM`
    （`BOND_INITIAL_FAM`，默认 8）、`new_bond()`；`update_bond()` 的兜底初值同步。
  - `bot/bonds.py`：`user()` 没记录时返回 `new_bond()`；`add_user_notes()` 新建记录用 `new_bond()`；
    `load()` 后跑一次 `_raise_floor()`，把老数据里 `0 <= 好感 < 10` 或 `熟悉 < 8` 的人抬到礼貌底线
    （好感为负、真被惹到的不动），用 `floor` 字段记账只迁一次。
- 验证：`tests/test_bonds.py` 新增两段——默认档是「普通」、老数据迁移只迁一次且不动负好感。

### 2. 新增 `/好感` 管理指令（仅 `DEV_UIN`）

- 用法：`/好感 @某人` 看；`/好感 @某人 +10` / `-10` 加减；`/好感 @某人 =30`（或直接 `30`）设定；
  `/好感 @某人 熟悉 +5` 调熟悉度。好感夹在 -100~100、熟悉 0~100。
- 改动：`bot/bonds.py` 新增 `set_levels(uid, name, aff, fam)`（返回改前/改后，供回复对比）；
  `bot/plugins/diary.py` 新增 `bond_cmd = on_command("好感", priority=17, block=True)`，
  沿用 `/小本本` 的守卫（机器人号 + `DEV_UIN`），回复带「改前→改后 + 当前态度档」。
- 验证：隔离实例 18081（`PERSONA_DATA_DIR` 指向临时目录）实测
  `好感 10→20`、`熟悉 8→42`、`/小本本` 读到同样的值。

### 3. 修「回复错人」：问句先答最后一条

- 现象：群友 A 两分钟前感叹「你咋回复这么快」，群友 B 随后 @ 她问「还有啥游戏能绑定uid」，
  她的回复却是「回得快也碍着你了」，还 @ 了 B——答案对着 A 的话，@ 却给了 B，看着就像答错人。
  日志（10-28 12:39:19）确认是 B 的事件、被叫@、回复内容却是 A 那句的续答。
- 改动：
  - `bot/persona_rules.py`：`SYSTEM_PROMPT` 加一句「历史里更早的发言已经聊过了：你只回最后那个人说的
    这句，别把几十秒前别人的话当成刚对你说的，也别答非所问。」；新增 `is_question(text)`（问号结尾或
    带疑问词）；`build_system_prompt()` / `compose_messages()` 新增 `question` 参数，命中时追加
    「最后这条是在问你事：先一句话直接回答他问的那个问题，别答非所问、别去接更早的别人的话」；
    `compose_messages()` 不传就自己按 `is_question()` 判断。求助（`help_mode`）优先，不叠加。
  - `bot/plugins/persona.py`：主回复路径算 `question`，问句放宽到 `MAX_CHARS_QUESTION`
    （`REPLY_MAX_CHARS_QUESTION`，默认 40 字）和 64 输出 token，避免「还有啥游戏能绑定uid」
    被 20 字截断。
- 验证：真模型探针 `_research/probe_question.py`（历史里带 A 的感叹）回复变成
  「原神崩铁绝区零都能绑，bbb乐土攻略查过了，先把uid绑了再说」；`tests/test_persona_rules.py`
  新增问句判定与提示词断言。
