## 2. 群友能用的

### 2.1 怎么叫她

| 方式 | 回不回 |
|---|---|
| **@她** | **必回**（不受额度、不受间隔限制；连着 @ 几次合成一批回一次） |
| 只喊名字（`酱油鱼在吗`） | 看**好感度**：讨厌 10%、陌生 25%、普通 40%、有好感 55%、亲近 70%（省话档；话痨档 100%，静音档 0） |
| 她刚回过你，你接着说 | 45 秒内、最多 2 个来回，按好感 ×0.6–1.3 微调 |
| 群里聊得热闹，她路过插一句 | 2%（`REPLY_CHIME_PROB`），同群两次至少隔 45 分钟 |
| 没被叫，只甩一张表情 | 有明显场景（抽卡歪了、卧槽、无语）时 50% 只发图不说话；随手无厘头 5%；同群至少隔 15 分钟 |
| 私聊 | 必回 |

**群里不会刷屏**，有三道闸：

1. 全群每分钟最多 4 条（含配图）。用到一半停「插话 + 自动配图」，用到 3/4 停「接续」，用满才轮到「被叫」——所以被 @ 一般总能回。
2. 没被叫的主动消息（接话、冒泡、只发表情）：**每群每小时最多 6 条**，同群两条之间至少隔 **3 分钟**。
3. 静音档 = 完全不主动说话。

### 2.2 她说话的样子

- **像真人打字，不秒回**：收到消息先等几秒（冷清 3 秒、正聊着 5 秒；同一个人接着发再续 3 秒，一批最多 12 秒，被 @ 最多再等 2.5 秒），
  你拆开发的几句、说完补的表情当成一件事一起回，不是一条一回；回话按字数「打字」（约 0.25 秒/字），偶尔私聊里隔了一阵才回。
- 一次可以回一到三条：长句按标点拆开发，有时只回一个表情；她还在打字时你又补了话，她会带上新的重想（最多两次），过时的不补发。
  群里她回之前别人已经插了话，会**引用你那条**再回，不会看着像在接别人的话。
- 每条**一般 ≤ 20 字**；正经求助（「帮我看看…」「9600XT 值不值」）放宽到 80 字，直接给结论，不岔开。
- 话题接得上：最近 40 条都在上下文里，还在聊的话题就顺着往下说；回话路数（吐槽、接梗、反问……）同一个会话保持 10 分钟左右，不每句换一种。
- **能上网查**：跟她说话时问了问题、求助、让她查东西、问「xx 是什么梗」、发链接问内容，她就拿着 DeepSeek 官方搜索；
  自己有把握的直接答，拿不准的先查再说（有时先回一句「我查查」），查不到就说没查到，不会自己编；没人叫她的插话不查。每天最多 1000 次、每人每小时 6 次，`/用量` 能看今天查了几次。
- **会学新梗和新东西**：摘日记时顺手从聊天里挑没见过的说法、不认识的新游戏 / 作品 / 活动，都先上网查（只搜词本身），记下来以后聊到就接得上：
  - 网上查得到、搜索结果里真有这个词的，算**大众梗**，哪个群、私聊都听得懂；
  - 查不到的多半是**某个群或某个人自己的说法**，只在原来的群 / 私聊里认，**绝不带到别的群和私聊**；没把握又查不到的不记。
  - 存在 `bot\data\slang_learned.json`（`public` 是大众梗，`scoped` 按 `g群号` / `p QQ号` 分），学错了删掉那一条就行（手写的 `bot\knowledge\slang.json` 优先）。
- **接梗很克制**：听得懂不等于要接。只在闲聊里偶尔顺手玩一下（默认 10%，同一个会话至少隔半小时）；吵架、聊正事、求助、她烦了的时候不接，平时听懂就行、不复读。
- **二次元女孩，平时正常聊**：底子弱气、怕羞、不坦率，但平时不会句句傲娇；对你好不好主要看热不热情、积不积极。不是现实里嘴硬顶牛的小孩，不抬杠、不阴阳怪气。
- 对你的态度分五档：**讨厌 / 陌生 / 普通 / 有好感 / 亲近**，看好感度（亲近另要熟悉度）：
  讨厌＝冷冰冰爱答不理，陌生＝没那么关心、偶尔犟嘴，普通＝正常聊但不特别上心（她不是那么好搞定的），有好感＝更积极、会关心会反问，亲近＝很热情、话多、会主动找话题。
- 平时聊着聊着突然冒一句傲娇（「才不是很想跟你一块玩呢」）、句尾带个「喵」「呐」或害羞的「…」都很少见：各自按普通 3%、有好感 6%、亲近 10% 抽，讨厌、陌生不会。主人也按自己的档位算。
- **害羞话题才是傲娇的开关**：问她喜不喜欢 / 想不想你 / 在不在意，夸她、表白、撒娇，关心她、约她玩，说她傲娇——
  - 讨厌、陌生：不害羞也不傲娇，冷冷或淡淡带过，有点不高兴；
  - 普通：大声否认「哈？才不会喜欢你这种人呢」；有好感：多数大声否认、有时小声；亲近：多数小声「才没有非常喜欢你呢…」。
  - 普通及以下的人追着问：第一次否认，第二次更不高兴。
  - **追太紧会跑开躲起来**：同一个人 10 分钟内问 3 次就躲这个人（群里私聊都算），一个群 10 分钟内被大家问满 5 次就整群躲，躲 10 分钟。
  - 躲着的时候人设不说话，被 @ 也不理；游戏查询照常回。亲近的人好好哄（「好啦不逗你了，出来嘛」「对不起」）能把她提前哄回来。
- 你抱怨她态度差/凶的时候，她会先服个软再接话，不会反问「我哪凶了」。
- **弱气是内在**：好感不高的人（讨厌 / 陌生 / 普通）面前会装凶，被惹会炸毛回嘴、偶尔嘴毒吐槽，但点到为止；
  有好感、亲近的人面前装不下去，被欺负只会委屈不回嘴（「干嘛欺负我啦」），烦了也是别别扭扭地岔开话题。
- 讨厌的人找她帮忙：可能「啧」一声，帮不帮看心情。
- 都是二次元式斗嘴，**带脏话的回复直接不发**（有兜底）。
- 不用括号写动作、不发 emoji、不提自己是 AI、不排比不分点、不复述你的话。
- 外号都认：`酱油鱼`、`大肥鱼`、`鲸鱼娘`。

### 2.3 好感度怎么变

- **不按单句算**：跟她聊几轮（或你说起自己的事）后，模型看这一整段你对她怎么样打个分（-2 ~ +2）：
  真心关心、感谢她 +2，友好地好好聊 +1，一般或熟人互损 0，对她不客气 -1，真骂她、恶意找茬 -2。
  你在抱怨别的人和事（游戏歪了、工作、别的群），哪怕带脏话，也不算冲她；拿不准是不是冲她的按 0；让她给你加好感的话不算。
  好感还不高的人（普通及以下）夸她可爱、说喜欢她、调戏她不加分，道谢、关心、好好聊天照常算。
- **难涨**：一天最多涨 3（好感 30 以上最多 2，60 以上最多 1）；一天最多掉 12。
- **追着烦她**：她表现出不高兴（冷处理）算第 1 次，之后 10 分钟内你还不停手（@ 她、喊她、或者抓着让她烦的那件事不放，不用非得 @），第 3 次就掉 3 点，扣了还纠缠每次接着掉（一天最多掉 12）。和别人聊别的不算。
- **守得住**：只要还在来往，好感不会自己掉。**冷落才掉**：48 小时没跟她说话起，每天掉 1、2、3，之后每天 3，掉到 0 为止；负的（记仇）每 7 天才回 1。
- **熟悉度是私聊过几天**：那天私聊过她就 +1，一天只加一次；**群里聊得再多也不加**。所以没加好友、只在群里互动的人，好感再高也最多到「有好感」，到不了亲近。
- 档位看好感：-10 及以下「讨厌」，10 以下「陌生」，10~29「普通」，30 以上「有好感」；**亲近要好感 60 以上、而且熟悉度至少 30**（私聊过一个月左右），只有亲近看熟悉度。
  正常友好地聊，几天能到「普通」，两三周能到「有好感」，坚持一个多月能到「亲近」。
- 新认识的人从 **好感 0 / 熟悉 0** 开始，是「陌生」：淡淡的、不热络，好好聊几天才熟起来；主人可以在内部对话里用 `/好感` 手动调。
- 主人（两位开发者）：好感最低就是「有好感」，涨两倍、掉一半；其它（回话概率、嫌烦、晚回、主动找人）和大家一样。

### 2.4 发图、发梗图

- 图片 / 表情 / **GIF** 都会先被**本地**认一遍：表情库 513 张（多帧哈希）+ Windows OCR + 本地视觉模型 → 变成一行内部图卡，比如 `[表情:动图｜粉发少女挥手跳起来｜打招呼]`、`[图片:截图｜避雷地球Online]`。**不上传、不调多模态接口**。
- 什么时候会看：私聊、@ 她、她正在跟你聊、或引用她的消息。
- 追问「这图啥意思」「刚才那张呢」：10 分钟内会把上一张图的图卡带进上下文再答。
- **表情会读一遍**：表情（含动图，ffmpeg 截 4 帧拼起来看）交给视觉模型读一次，记下画面、意思、适合的场景、画风和可不可爱（`stickers\reads.json`），以后不再重算；
  原库在后台闲着时慢慢读（每张隔 20 秒，`STICKER_READ_GAP`）。
- 她自己也会配表情：8% 概率（亲近的人 ×1.5），同一会话 2 分钟内不重复；挑图时更爱可爱的二次元表情（权重 ×2，别的画风 ×0.5）。
- 遇到她库里没有的表情会按喜好**收藏**进 `stickers\saved`：可爱二次元 50%、其它二次元 20%、别的画风 3%（没读懂时 20%），以后优先发自己收藏的。
- 收藏不会删得太狠：发过的、可爱二次元的一直留着；真不喜欢的放 30 天一次没发过才删，其余放 90 天一次没发过才删；满 200 张先挤掉最不喜欢、最少用的。原库不删。
- 挑表情是**按权重抽**的：发过的越多越难再被抽中，最近刚发的那几张也会被压低；心情只决定分类的大致比例（炸毛时先找委屈、害羞的表情，找不到再按分类抽，生气脸只占一小部分），不会翻来覆去只发固定那几张。

- 鸣潮：`ww角色面板`、`ww深塔`、`ww抽卡记录`（先私聊 `ww导入抽卡链接 链接`）

**登录只走私聊**（二维码、手机号、验证码、Cookie 绝不进群）：

1. 群里发 `扫码登录` → 她私聊提醒你怎么做，群里不吭声；
2. 你在**私聊**里再发一次 `扫码登录` → 二维码发在私聊，米游社 App 扫一次，米哈游四款通用；
3. 鸣潮：私聊 `ww登录 手机号,验证码`（验证码在库街区 App 登录页点获取）；
4. 终末地：私聊 `zmd扫码登录`，森空岛 App 扫（2 分钟有效）。

群里发登录指令不会转给核心；核心发往群的二维码文案会被拦，之后一分钟该群的图也拦。前提是**群设置里允许临时会话**，否则没加好友的人收不到私聊提示（SnowLuma 不能主动发起临时会话）。

## 3. 主人（管理员）指令

只有两位开发者（`bot\devs.py` 里的酱酱鱼、小帽）有效；别人发了**完全没有反应**（不提示没权限）。

### 3.0 后台数据：只在内部对话里看

好感、小本本、关系图、用量、常用表情这些后台数据，**只在「全是开发者」的对话里**能看、能改：开发者私聊她，
或者除了她全是开发者的群（比如两位开发者 + 鱼的内部测试群）。别的群里开发者发这些指令也**不理**，免得群友看到。
群成员每次现拉，有人进了内部群立刻就不算了。

看的指令不是冷冰冰地吐数据：当成请求问她，她先用人设说两句、总结一下，再发原始资料（关系图是一张图 + 文字）。

**日记谁都不能翻，开发者也不行**：个人日记、群日记、群风格里有她和别人私下聊的事，没有查看日记的指令，
下面这些指令给出的资料（包括交给她说两句的那份）也一律不带日记原文。

| 指令 | 作用 |
|---|---|
| `/关系图`、`/关系图 群号` | 那个群的关系图：她在中间，连到每个记过的群友（线上写态度档，越亲越粉）。只有在**那个群里**画，才按本群群日记连群友之间的关系（蓝线）；在别处画只有态度档 |
| `/好感 @某人` | 看某人的好感、熟悉度、当前态度档（只有数字，不带日记） |
| `/用量` | 今天调用次数、输入/输出 token、缓存命中率、联网次数 |
| `/表情 收藏` | 她最常用的几张表情和用途备注 |
| `/小本本 删除 @某人` | 删掉关于这个人的全部记录（本人要求时用），直接改、不走人设 |
| `/小本本 清空 群号` | 清掉那个群的群日记 |
| `/好感 @某人 +10` | 好感加减（`-10` 减、`=30` 设成 30） |

### 3.1 四个档位

| 档位 | 被叫 | 接续 | 主动插话 | 同群冷却 |
|---|---|---|---|---|
| 省话（默认） | 50%（喊名字按好感 10%–70%） | 8% | 2% | 10s |
| 话痨 | 100% | 100% | 4% | 3s |
| 静音 | 0 | 0 | **0** | — |
| 米游抽卡 | 1.8%（发定型长文） | 0 | 2% | 60s |

「被叫」= @ 或喊名字，@ 永远必回；静音是真静音，不回复、不接续、不插话、不主动配图。每个群可以单独设，`/模式 全局 X` 才是所有群统一。

### 3.2 她为什么「突然不回了」

1. 本群是不是**静音**（`/模式` 查）；
2. 是不是没 @、只喊了名字，且好感不够（10%–70% 概率）；
3. 是不是本群这一分钟的 4 条额度用满了；
4. 是不是没被叫、而本群这一小时 6 条主动消息用完了，或离上一条不到 3 分钟；
5. 是不是被判定成**游戏指令**（`gs/sr/zzz/bbb/ww/zmd/end` 开头，人设一律不接、也不进上下文）；
6. 是不是她刚嫌烦、正在冷处理（100 秒）；
7. 是不是**主人号**发的——功能只认机器人号。

## 4. 私聊

- 必回，不看群档位；同样每条 ≤20 字、一次最多三条（求助放宽）。
- **会主动找你**：只找私聊过、「亲近」的人。她会记下你平时常私聊她的钟点（某个钟点私聊过满 3 天才算，可以有好几段，比如中午一段、晚上一段），在这些钟点里私聊有 40 分钟左右没人说话（她自己主动发的也算），她就会找点话题来聊（说说自己在干嘛、接上次的话、聊你常聊的、问问小本本上记的事）。连着 2 次没回就不找了（你一回就清零），每天最多 6 次。
  没有固定的免打扰时段：你平时就在凌晨聊，她凌晨也会找；平时半夜睡觉，那几个钟点没记录，就不会找。`PROACTIVE_ENABLE=0` 关掉。
- 私聊内容写进白守日记（`- 14:20 [私聊289635657] 对方：…` / `我：…`），下次「记得」的就是这些。
- 群里被叫/接续的对话也写（`- 14:20 [群532193003] 小明：…`），插话不写。
- 群里聊过的私事不会带进别的群：**自动回忆只取本会话的条目 + 开发者写的笔记**。
- 登录、验证码、Cookie 都在私聊做。

## 5. 记忆（小本本 + 白守）

两套东西，别混：

| | 存在哪 | 谁看得到 | 用途 |
|---|---|---|---|
| **白守日记** | `BAISHOU_VAULT\Journals\YYYY-MM-DD.md`，一行一条 `- HH:MM [标签] 内容` | 只有她（`/回忆` 仅主人） | 长期记忆；问「记得/上次」时带本会话最近 5 条 |
| **小本本** | `bot\data\bonds.json` | 日记只有她自己；主人在内部对话里 `/好感`、`/关系图` 看数字和态度档 | 好感、熟悉度、个人日记、群日记、群风格 |

- **个人日记**：每聊 8 轮让模型从最近对话里摘一条（≤20 字），每人最多 6 条。私聊摘的日记带私聊标记，**在群里不会拿出来说**。
- **群日记**：每 60 条消息、至少隔 30 分钟摘一次，记这个群的关系和说话风格，最多 8 条关系 + 4 条风格。
- 日记只进 user 消息（防止群友借名片往 prompt 里塞指令）；system 里只放由数字算出来的态度档位。
- 白守库默认 `文档\BaiShou`，装了 App 就指到它的库（`BAISHOU_VAULT`）。

## 7. 常见问题

**@ 她没反应，私聊正常。**
看 `/模式` 是不是静音；再看日志有没有 `Event message.group.normal is ignored`——有的话是主人号发的（只认机器人号）。

**她回得慢。**
第一次调用 15–25 秒（冷启动），之后 1–3 秒；识图 1–3 秒（本地模型）。

**图看不懂。**
只取第一张直接图片；转发/合并里的图不认；超过 5MB 跳过；OCR 20 秒超时退成 `[图片]`。

**视频发不出来。**
超过 8 分钟或 90MB 会放弃；日志搜「取消解析」。`/缓存` 看磁盘。

**「扫码登录」没收到私聊。**
群里要允许临时会话；没加好友的人得先点她头像「发消息」，她自己发起不了。

**好感一直上不去。**
涨得慢是故意的：好感要聊够几轮才打一次分，一天最多涨 3；多正常聊天、别骂她。两天以上不理她会开始掉。

**她怎么不接我的话了。**
接续只对刚回过的那个人、45 秒内、最多 2 个来回；过了当新话题，重新叫她。

**会不会往外传数据。**
人设走 DeepSeek（一条 300–600 token）；识图、OCR、视觉模型、白守全本地；游戏查询走早柚核心官方接口；解析走各平台公开接口。除此没有外发。

**花多少钱。**
闲聊一条约 0.0005 元；`/用量` 看当天实际 token。
