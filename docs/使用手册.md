# 酱油鱼 · 使用手册

> 这份讲**装好之后怎么用**：群里怎么叫她、她能干什么、主人指令、出问题怎么查。
> 装 / 更新 / 换机器见 [部署指南](部署指南.md)；端口和进程见 [架构与运维](架构与运维.md)；游戏查询细节见 [早柚核心接入](早柚核心接入.md)。

## 0. 一句话

QQ 群里的一个**傲娇二次元群友**。被叫会回一两句，偶尔自己冒泡，被追问烦了会甩脸子；能看懂图和表情（含 GIF，本地识别，不调多模态）、能发 B 站视频、能用早柚核心查六款游戏的数据和抽卡记录；好感度、日记、私人记忆都存在本地。

```
QQ NT（登录两个号）→ SnowLuma（3000/3001/5099）
                        └─反向 WS→ NoneBot2（18080）
                                     ├─ 人设 / 小本本 / 表情 / 记忆
                                     ├─ 解析（B站等）+ 本地识图
                                     └─ 早柚核心（8765）→ gs/sr/zzz/bbb/ww/zmd
本地视觉模型（11435）只给识图兜底
```

机器人号 = `BOT_UIN`，主人号 = `DEV_UIN`。**功能只认机器人号**：主人号在同一群里发的消息会被整个跳过（不回话、不进上下文、不记账）。

## 2. 群友能用的

### 2.1 怎么叫她

| 方式 | 回不回 |
|---|---|
| **@她** | **必回**（不受额度、不受间隔限制；连着 @ 几次合成一批回一次） |
| 只喊名字（`酱油鱼在吗`） | 看**好感度**：讨厌 10%、陌生 25%、普通 40%、有好感 55%、亲近 70%（省话档；话痨档 100%，静音档 0） |
| 她刚回过你，你接着说 | 45 秒内、最多 2 个来回，按好感 ×0.6–1.3 微调 |
| 群里聊得热闹，她路过插一句 | 2%（`REPLY_CHIME_PROB`），同群两次至少隔 45 分钟 |
| 没被叫，只甩一张表情 | 有明显场景（抽卡歪了、卧槽、无语）时 50% 只发图不说话；随手无厘头 5%；同群至少隔 15 分钟 |
| 私聊 | 必回 |

**群里不会刷屏**，有三道闸：

1. 全群每分钟最多 4 条（含配图）。用到一半停「插话 + 自动配图」，用到 3/4 停「接续」，用满才轮到「被叫」——所以被 @ 一般总能回。
2. 没被叫的主动消息（接话、冒泡、只发表情）：**每群每小时最多 6 条**，同群两条之间至少隔 **3 分钟**。
3. 静音档 = 完全不主动说话。

### 2.2 她说话的样子

- **像真人打字，不秒回**：收到消息先等几秒（冷清 3 秒、正聊着 5 秒；同一个人接着发再续 3 秒，一批最多 12 秒，被 @ 最多再等 2.5 秒），
  你拆开发的几句、说完补的表情当成一件事一起回，不是一条一回；回话按字数「打字」（约 0.25 秒/字），偶尔私聊里隔了一阵才回。
- 一次可以回一到三条：长句按标点拆开发，有时只回一个表情；她还在打字时你又补了话，她会带上新的重想（最多两次），过时的不补发。
  群里她回之前别人已经插了话，会**引用你那条**再回，不会看着像在接别人的话。
- 每条**一般 ≤ 20 字**；正经求助（「帮我看看…」「9600XT 值不值」）放宽到 80 字，直接给结论，不岔开。
- 话题接得上：最近 40 条都在上下文里，还在聊的话题就顺着往下说；回话路数（吐槽、接梗、反问……）同一个会话保持 10 分钟左右，不每句换一种。
- **傲娇是调味，不是全程怼人**：平时像普通熟人一样正常接话，被逗、被夸、被惹的时候才嘴硬一下；没人挑衅时不反问、不挑刺、不阴阳怪气。
- 对你的态度分五档：**讨厌 / 陌生 / 普通 / 有好感 / 亲近**，由好感度和熟悉度算出来，语气跟着变：
  讨厌＝冷淡话少，陌生＝客气有距离，普通＝正常聊天偶尔嘴硬，有好感＝语气变软、愿意多聊会关心，亲近＝放松亲昵、会护短撒娇。
- 「露真心」概率也随好感涨：普通 10%、有好感 30%、亲近 45%（主人固定 50%）。
- 你抱怨她态度差/凶的时候，她会先服个软再接话，不会反问「我哪凶了」。
- 可以毒舌、放狠话，但**带脏话的回复直接不发**（有兜底）。
- 不用括号写动作、不发 emoji、不提自己是 AI、不排比不分点、不复述你的话。
- 外号都认：`酱油鱼`、`大肥鱼`、`鲸鱼娘`。

### 2.3 好感度怎么变

- **涨**：说「谢谢 / 厉害 / 好棒 / 辛苦了 / 晚安 / 早安」、正常聊天、被 @ 后好好说话。
- **掉**：骂人（傻逼、闭嘴、滚、废物…）、阴阳怪气、刷屏骚扰。
- **冷落会淡化**：几天不理她，好感会掉一点（有 3 天宽限期）。
- 好感 + 熟悉度决定档位：骂多了会到「讨厌」，回得又短又冷。
- 新认识的人默认 **好感 10 / 熟悉 8**（态度「普通」，正常聊天、偶尔嘴硬），不是一上来就爱答不理；主人可以用 `/好感` 手动调。
- 主人（`DEV_UIN`）单独算：好感度照常记账，但「露真心」概率固定 20%。

### 2.4 发图、发梗图

- 图片 / 表情 / **GIF** 都会先被**本地**认一遍：表情库 513 张（多帧哈希）+ Windows OCR + 本地视觉模型兜底 → 变成一行内部图卡，比如 `[表情:动图｜其他｜截图选老婆]`、`[图片:截图｜避雷地球Online]`。**不上传、不调多模态接口**。
- 什么时候会看：私聊、@ 她、她正在跟你聊、或引用她的消息。
- 追问「这图啥意思」「刚才那张呢」：10 分钟内会把上一张图的图卡带进上下文再答。
- 她自己也会配表情：8% 概率（炸毛时翻倍），同一会话 2 分钟内不重复；遇到她库里没有的表情，20% 概率**收藏**进 `stickers\saved`，以后优先发自己收藏的。
- 挑表情是**按权重抽**的：发过的越多越难再被抽中，最近刚发的那几张也会被压低；心情只决定分类的大致比例（炸毛时约 1/3 是生气脸，其余分给无文字和别的），不会翻来覆去只发固定那几张。

### 2.5 丢链接

| 平台 | 结果 |
|---|---|
| B 站 | 视频合并音轨后直接发文件；图文/番剧发卡片 |
| 小红书 / 抖音 / 快手 / 微博 / NGA / 小蓝鸟 / 猴山 | 图文卡片，视频同 B 站 |

限制：单文件 ≤ 90MB、时长 ≤ 8 分钟，超了静默放弃；没配 B 站 Cookie 只有 480P。缓存保留 24 小时，每小时自动清。

### 2.6 游戏查询（早柚核心）

| 游戏 | 前缀 | 第一次用 |
|---|---|---|
| 原神 | `gs` | `gs绑定uid 你的UID` |
| 星铁 | `sr` | `sr绑定uid …` |
| 绝区零 | `zzz`、`绝区零` | `zzz绑定uid …` |
| 崩坏3 | `bbb` | `bbb绑定uid …` |
| 鸣潮 | `ww` | `ww绑定 特征码` |
| 终末地 | `zmd`、`end` | 不用绑，直接登录 |

常用（每个插件的 `帮助` 最全，如 `gs帮助`）：

- 原神：`gs查询胡桃`、`gs深渊`、`gs强制刷新`、`gs刷新抽卡记录` → `gs抽卡记录`
- 星铁：`sr查询希儿`、`sr深渊`、`sr练度统计`、`sr刷新抽卡记录` → `sr抽卡记录`
- 绝区零：`zzz查询露西`、`zzz深渊`、`zzz刷新面板`、`zzz刷新抽卡记录` → `zzz抽卡记录`
- 鸣潮：`ww角色面板`、`ww深塔`、`ww抽卡记录`（先私聊 `ww导入抽卡链接 链接`）
- 终末地：`zmd卡片`、`zmd每日`、`zmd签到`、`zmd基建`、`zmd刷新抽卡记录`

**登录只走私聊**（二维码、手机号、验证码、Cookie 绝不进群）：

1. 群里发 `扫码登录` → 她私聊提醒你怎么做，群里不吭声；
2. 你在**私聊**里再发一次 `扫码登录` → 二维码发在私聊，米游社 App 扫一次，米哈游四款通用；
3. 鸣潮：私聊 `ww登录 手机号,验证码`（验证码在库街区 App 登录页点获取）；
4. 终末地：私聊 `zmd扫码登录`，森空岛 App 扫（2 分钟有效）。

群里发登录指令不会转给核心；核心发往群的二维码文案会被拦，之后一分钟该群的图也拦。前提是**群设置里允许临时会话**，否则没加好友的人收不到私聊提示（SnowLuma 不能主动发起临时会话）。

### 2.7 自动签到

登录过就自动领，不用发指令：米哈游系每天签到前用 Stoken 自动续 Cookie；鸣潮、终末地启动即开「全部签到」。结果**不私聊推送**（发不出去），想看自己发 `gs签到` / `sr签到` / `zzz签到` / `ww签到` / `zmd签到`。

| `/用量` | 今天调用次数、输入/输出 token、缓存命中率 |
| `/记 <内容>` | 往白守日记写一条（署名开发者，任何会话都能被带出） |
| `/回忆 <关键词>` | 搜本会话的历史日记 |

| `/缓存`、`/缓存 清理` | 看/清解析缓存 |
| `/ping` | 回 `pong` |

### 3.1 四个档位

| 档位 | 被叫 | 接续 | 主动插话 | 同群冷却 |
|---|---|---|---|---|
| 省话（默认） | 50%（喊名字按好感 10%–70%） | 8% | 2% | 10s |
| 话痨 | 100% | 100% | 4% | 3s |
| 静音 | 0 | 0 | **0** | — |
| 米游抽卡 | 1.8%（发定型长文） | 0 | 2% | 60s |

「被叫」= @ 或喊名字，@ 永远必回；静音是真静音，不回复、不接续、不插话、不主动配图。每个群可以单独设，`/模式 全局 X` 才是所有群统一。

### 3.2 她为什么「突然不回了」

1. 本群是不是**静音**（`/模式` 查）；
2. 是不是没 @、只喊了名字，且好感不够（10%–70% 概率）；
3. 是不是本群这一分钟的 4 条额度用满了；
4. 是不是没被叫、而本群这一小时 6 条主动消息用完了，或离上一条不到 3 分钟；
5. 是不是被判定成**游戏指令**（`gs/sr/zzz/bbb/ww/zmd/end` 开头，人设一律不接、也不进上下文）；
6. 是不是她刚嫌烦、正在冷处理（100 秒）；
7. 是不是**主人号**发的——功能只认机器人号。

## 4. 私聊

- 必回，不看群档位；同样每条 ≤20 字、一次最多三条（求助放宽）。
- 私聊内容写进白守日记（`- 14:20 [私聊289635657] 对方：…` / `我：…`），下次「记得」的就是这些。
- 群里被叫/接续的对话也写（`- 14:20 [群532193003] 小明：…`），插话不写。
- 群里聊过的私事不会带进别的群：**自动回忆只取本会话的条目 + 开发者写的笔记**。
- 登录、验证码、Cookie 都在私聊做。

## 5. 记忆（小本本 + 白守）

两套东西，别混：

| | 存在哪 | 谁看得到 | 用途 |
|---|---|---|---|
| **白守日记** | `BAISHOU_VAULT\Journals\YYYY-MM-DD.md`，一行一条 `- HH:MM [标签] 内容` | 只有她（`/回忆` 仅主人） | 长期记忆；问「记得/上次」时带本会话最近 5 条 |
| **小本本** | `bot\data\bonds.json` | 主人 `/小本本` | 好感、熟悉度、个人日记、群日记、群风格 |

- **个人日记**：每聊 8 轮让模型从最近对话里摘一条（≤20 字），每人最多 6 条。私聊摘的日记带私聊标记，**在群里不会拿出来说**。
- **群日记**：每 60 条消息、至少隔 30 分钟摘一次，记这个群的关系和说话风格，最多 8 条关系 + 4 条风格。
- 日记只进 user 消息（防止群友借名片往 prompt 里塞指令）；system 里只放由数字算出来的态度档位。
- 白守库默认 `文档\BaiShou`，装了 App 就指到它的库（`BAISHOU_VAULT`）。

## 6. 参数（`bot\persona.env`）

每项上面都有中文说明。改完 `一键停止.cmd` → `一键启动.cmd` 生效。

> **一键更新会按样例重写这些调参项**（账号、密钥、路径保留，并备份成 `persona.env.bak-时间`）。想长期保留自己调的值，写进 `bot\persona.local.env`（只写要改的几行，后读、覆盖同名项、更新不碰）。

| 键 | 默认 | 说明 |
|---|---|---|
| `REPLY_MAX_CHARS` / `REPLY_MAX_CHARS_HELP` | 20 / 80 | 每条消息 / 求助时一次回话的字数上限 |
| `REPLY_MAX_LINES` / `REPLY_TOTAL_CHARS` | 3 / 60 | 一次回话最多几条 / 总字数 |
| `DEBOUNCE_QUIET` / `DEBOUNCE_BUSY` / `DEBOUNCE_SAME_USER` / `DEBOUNCE_MAX` / `DEBOUNCE_AT` | 3 / 5 / 3 / 12 / 2.5 | 等对方说完：冷清 / 正聊着先等几秒、同一个人续几秒、一批最多几秒、被 @ 最多再等几秒 |
| `TYPING_SEC_PER_CHAR` / `TYPING_MAX_SEC` / `REPLY_LATE_PROB` | 0.25 / 8 / 0.1 | 打字速度 / 单条最长打字时间 / 私聊偶尔晚回的概率 |
| `REPLY_PROB_CALLED` | 0.5 | 喊名字概率的基准（按好感缩放，改它等比缩放） |
| `REPLY_PROB_FOLLOW` | 0.08 | 接续概率 |
| `REPLY_CHIME_PROB` / `REPLY_CHIME_COOLDOWN` | 0.02 / 2700 | 主动插话概率 / 同群最短间隔 |
| `REPLY_GROUP_PER_HOUR` / `REPLY_CASUAL_GAP` | 6 / 180 | 每群每小时主动消息上限 / 同群两条间隔 |
| `REPLY_PER_MIN` | 4 | 全群每分钟上限（含配图，按档位停不同类型） |
| `ENGAGE_TTL` / `ENGAGE_FOLLOW_WINDOW` / `ENGAGE_MAX_TURNS` | 120 / 45 / 2 | 接续有效期 / 间隔 / 最多来回 |
| `STICKER_AUTO_PROB` / `STICKER_AUTO_COOLDOWN` | 0.08 / 600 | 自动配图概率 / 间隔 |
| `STICKER_ONLY_PROB` / `STICKER_RANDOM_PROB` | 0.5 / 0.05 | 只发图（有场景 / 无厘头） |

## 7. 常见问题

**@ 她没反应，私聊正常。**
看 `/模式` 是不是静音；再看日志有没有 `Event message.group.normal is ignored`——有的话是主人号发的（只认机器人号）。

**她回得慢。**
第一次调用 15–25 秒（冷启动），之后 1–3 秒；识图 1–3 秒（本地模型）。

**图看不懂。**
只取第一张直接图片；转发/合并里的图不认；超过 5MB 跳过；OCR 20 秒超时退成 `[图片]`。

**视频发不出来。**
超过 8 分钟或 90MB 会放弃；日志搜「取消解析」。`/缓存` 看磁盘。

**「扫码登录」没收到私聊。**
群里要允许临时会话；没加好友的人得先点她头像「发消息」，她自己发起不了。

**好感一直上不去。**
涨得慢是故意的（难涨易掉），多正常聊天、别骂人；几天不理她会淡化。

**她怎么不接我的话了。**
接续只对刚回过的那个人、45 秒内、最多 2 个来回；过了当新话题，重新叫她。

**会不会往外传数据。**
人设走 DeepSeek（一条 300–600 token）；识图、OCR、视觉模型、白守全本地；游戏查询走早柚核心官方接口；解析走各平台公开接口。除此没有外发。

**花多少钱。**
闲聊一条约 0.0005 元；`/用量` 看当天实际 token。

## 9. 安全提醒

- `persona.env` 里有 API Key 和 OneBot token，**不要提交、不要截图外发**；仓库里只有 `persona.env.example`。
- 群名片会进 prompt，所以名字统一走 `safe_name` 清洗；别把「名字 → 身份」的判断写死成字符串比较。
- 二维码、手机号、验证码、Cookie 只走私聊，群里的会被拦。
- key 疑似泄露就轮换，再改 `persona.env` 重启。
