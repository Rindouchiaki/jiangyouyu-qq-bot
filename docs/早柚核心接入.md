# 早柚核心接入：星铁 / 绝区零 / 崩坏3

> 只支持国服（米游社）。扫码登录走米游社，HoYoLab 国际服没有扫码，不在本方案范围内。

## 一、它是什么

游戏查询不再自己写，交给 [早柚核心 gsuid_core](https://github.com/Genshin-bots/gsuid_core) 加三个插件：

| 游戏 | 插件 | 指令前缀 |
|---|---|---|
| 崩坏：星穹铁道 | [StarRailUID](https://github.com/baiqwerdvd/StarRailUID) | `sr` |
| 绝区零 | [ZZZeroUID](https://github.com/ZZZure/ZZZeroUID) | `zzz`、`绝区零`、`ZZZ` |
| 崩坏3 | [BBBUID](https://github.com/Neroliu/BBBUID) | `bbb`、`崩坏3`、`BBB` |

```
QQ ─ SnowLuma ─ 反向 WS ─ NoneBot2（18080）
                            ├─ persona 等原有插件
                            └─ GenshinUID 连接插件 ─ WS ─ 早柚核心（127.0.0.1:8765）
                                                            ├─ StarRailUID
                                                            ├─ ZZZeroUID
                                                            └─ BBBUID
```

- 核心是**单独的进程**，不直连 QQ；NoneBot 里的连接插件 `nonebot-plugin-genshinuid` 把**每一条**消息转给它，由它判断是不是游戏指令。
- 核心的回复走连接插件发出，**不经过人设插件，不计入群聊限流**。
- 人设插件看到 `GAME_CMD_PREFIXES`（默认 `sr,zzz,bbb,扫码登录,扫码登陆`）开头的消息不接话、不进上下文和日记。
- 核心没开时连接插件只报错，人设照常。

## 二、安装（Windows 主机）

1. 装 [uv](https://docs.astral.sh/uv/)，确认 `uv --version` 能用。
2. 装核心（放在 `Z:\snowluma\gsuid_core`，和仓库分开，**数据目录里有群友的米游社凭据，不要进 git**）：

   ```powershell
   cd Z:\snowluma
   git clone https://github.com/Genshin-bots/gsuid_core.git --depth=1 --single-branch
   cd gsuid_core
   uv sync --python 3.13
   ```

3. 装三个插件：

   ```powershell
   cd Z:\snowluma\gsuid_core\gsuid_core\plugins
   git clone https://github.com/baiqwerdvd/StarRailUID.git --depth=1 --single-branch
   git clone https://github.com/ZZZure/ZZZeroUID.git --depth=1 --single-branch
   git clone https://github.com/Neroliu/BBBUID.git --depth=1 --single-branch
   ```

4. 机器人这边装连接插件：`.\.venv\Scripts\pip install -r requirements.txt`（已包含 `nonebot-plugin-genshinuid`）。
5. `bot\persona.env` 里加上 `persona.env.example` 中「早柚核心」那几项（同机部署照抄即可，`GSUID_CORE_REPEAT=true` 让核心重启后自动重连）。
6. 启动：`.\scripts\启动全部.ps1` 会先起核心再起 NoneBot；不想起核心加 `-NoCore`。首次启动核心会装依赖、生成 `data\config.json`，可能超过脚本等待的 90 秒，看 `logs\gscore.out.log` 和 `logs\gscore.err.log`。

## 三、配置（核心网页控制台 `http://127.0.0.1:8765/app`）

注册码在 `Z:\snowluma\gsuid_core\data\config.json` 的 `REGISTER_CODE`。

| 项 | 怎么设 | 为什么 |
|---|---|---|
| 主人账号 `masters` | 填 `DEV_UIN` | 核心的管理指令（`core安装插件`、`core重启` 等）只给主人 |
| 「扫码登陆」服务 | 作用范围改为 `DIRECT` | 二维码只发在私聊（群临时会话），不会被群里别人先扫走；机器人这边另有拦截，见第四节 |
| `core_command` 插件作用范围 | 保持默认 `SV` | 改成 `ALL` 会盖过上面那条服务级的 `DIRECT` |
| `EnableForwardMessage` | 保持「允许」 | 改成拆条发送时，二维码会和文案分开发；机器人这边的群内拦截靠文案认出二维码 |
| 「添加CK」服务 | 保持默认 `DIRECT` | `core添加…` 是粘贴 Cookie，只在私聊收，凭据不会出现在群里 |
| 自动签到 | 每个人默认不开 | 插件的全局定时签到默认开着，但只给自己开过自动签到的人签 |
| `WS_TOKEN` / `TRUSTED_IPS` | 保持默认 | 同机只信任 127.0.0.1；核心挪到别的机器时再配 token，并同步 `GSUID_CORE_WS_TOKEN` |

素材：主人在群里发 `sr下载全部资源`，其它两个插件按各自 `帮助` 里的资源指令下载。

## 四、群设置与群友用法

1. **群里要允许临时会话**（群设置里打开），机器人才能不加好友就私聊群友。
2. 先在群里绑 UID（扫码前必须至少绑一个游戏）：`sr绑定uid 123456789`、`zzz绑定uid …`、`bbb绑定uid …`。
3. 群里发「扫码登录」：`bot/plugins/gscore_login.py` 只在临时会话里告诉对方怎么做，**群里不回任何话**。对方**在临时会话里**回「扫码登录」，核心把二维码发在那里，用米游社 App 扫一次，三个游戏共用这一个登录。
   二维码绝不进群，机器人这边有三道保险：群里的登录指令不转给核心（空格、表情隔开也认）；临时会话发不出去也不在群里补话；发往群的消息带二维码文案就拦下，并在之后一分钟里拦掉发往该群的图片。
4. 之后在群里直接查，常用指令（以各自 `sr帮助`、`zzz帮助`、`bbb帮助` 为准）：

| | 星铁 | 绝区零 | 崩坏3 |
|---|---|---|---|
| 抽卡 | `sr刷新抽卡记录` → `sr抽卡记录` | `zzz刷新抽卡记录` → `zzz抽卡记录` | `bbb刷新抽卡记录` → `bbb抽卡记录` |
| 深渊类 | `sr深渊`（另有虚构叙事、末日幻影等） | `zzz深渊`（式舆防卫战） | `bbb深渊`、`bbb战场`、`bbb往世乐土` |
| 角色 / 面板 | `sr强制刷新` → `sr查询希儿`、`sr练度统计` | `zzz刷新面板` → `zzz查询露西`、`zzz练度统计` | `bbb刷新面板`、`bbb查询` |

## 五、迁移

- 原来自写的 `/hsr`、`/zzz` 已下线，`Z:\snowluma\game-data`（角色缓存和 `/hsr 绑定` 的 `bindings.json`）不再使用：群里通知大家在核心里重新绑 UID，确认没问题后把这个目录归档或删掉。
- `persona.env` 里的 `GAME_DATA_TTL`、`GAME_DATA_CHECK_INTERVAL`、`MYS_COOKIE` 可以删掉。

## 六、已知问题

- 官方文档提醒：QQ 机器人发二维码图片可能触发腾讯风控。
- 机器人主动发起的临时会话可能被 QQ 限制或静默丢掉，群里也不会有提示；没收到就让对方自己点机器人头像发起临时会话，发「扫码登录」。
- 人设按前缀避让，`zzz困死了`、`bbb笑死` 这类聊天人设也会闭嘴（核心也不会回）；可在 `GAME_CMD_PREFIXES` 里调整；反过来「绝区零」「崩坏3」开头的指令（如 `绝区零深渊`）不在默认前缀里，人设可能和核心一起回。
- 崩坏3 插件 BBBUID 较新（2026-05 创建、单人维护），没有前两款那种完整面板。
- 协议：核心与 StarRailUID 是 GPL-3.0、ZZZeroUID 是 AGPL-3.0，BBBUID 仓库没有许可证文件；我们只作为独立服务运行，不把它们的代码并进本仓库。
